# 用户验收清单

## 发布身份

- [ ] 页面显示的应用版本与本次计划发布版本一致。
- [ ] 已记录 source SHA 和构建产物 hash。
- [ ] 已记录 Netlify 和 GitHub Pages 的入口角色。
- [ ] 已确认 Netlify 控制台绑定的仓库和生产分支。

## 核心操作

- [ ] 通过 `npm run dev` 打开应用，Console 没有真实错误。
- [ ] Timer、Odds、Review 三个 Tab 都能打开。
- [ ] Review 下的子 Tab 都能打开。
- [ ] 生产构建生成可用的单文件 `dist/index.html`。
- [ ] 构建文件可以通过 `file://` 打开。
- [ ] 在浏览器允许时，HTTPS 模式可以注册 Service Worker。

## 数据安全

- [ ] 可以导入 GG hand history。
- [ ] 可以一次选择多份 .txt 导入，预览顺序与文件选择顺序一致。
- [ ] 可以识别重复手牌（含多份文件之间的重复），不产生意外重复记录。
- [ ] 导入后原有手工复盘字段仍然保留。
- [ ] 导出的数据可以导入新的本地用户环境。
- [ ] IndexedDB 降级或 safe mode 会显示明确的存储状态。
- [ ] 正常使用时不会向外部 endpoint 发送用户数据。

## 代表性扑克行为

- [ ] `uncalled` bet 不计入实际投入金额。
- [ ] Ante、rake、jackpot 和 collected amount 表示正确。
- [ ] 解析后仍保留 board texture 和 board metadata。
- [ ] 混合档位（如 NL5 与 NL10）合并导入时，各手牌的 BB 盈亏按自己档位换算正确。
- [ ] Session 自动分组等级与盲注一致（NL5/NL10），同日不同档位不会并成一场。
- [ ] 修改或删除手牌后重新打开 Discover，结果按最新数据刷新（手牌数量不变时也要刷新）。
- [ ] Discover / Quiz / GTO 速查中的 GTO 对照均标注为"旧 GTO 参考"（适用范围未验证），不再自动出现"偏离 GTO"结论。
- [ ] Discover 发现的问题可以追溯到对应手牌。
- [ ] Quiz 答错后和重试后反馈仍然可用。

## 每场收尾（Phase 1）

- [ ] Review 的 Session 面板内有「⚡ 快速记录 Mark」按钮，点开可直接写一句备注保存。
- [ ] 有手牌的未收尾 Session 行显示「未收尾」徽章，面板顶部显示待收尾计数。
- [ ] 点 🏁 展开收尾工作区：Mark 与 ±5 分钟内的导入手牌可以一键确认关联，也可标"无对应"。
- [ ] 候选手牌清单带来源徽章（Mark/大亏损/高杠杆/星标），可以标"已看"并跳转手牌详情。
- [ ] 「确认收尾」后该场徽章消失、待收尾计数减少；重开应用进度仍在。
- [ ] Timer 的计时行为与收尾流程互不影响。

## Decision Radar（Phase 2）

- [ ] 手牌 ≥50 且有命名场景样本时，Discover 面板出现「🎯 Decision Radar」区块。
- [ ] 信号卡显示 你的频率 vs 场景基线、样本量与场景分组，并注明"归属为启发式"。
- [ ] 「查看手牌」可展开证据手牌列表并跳转手牌详情。
- [ ] 「建档研究」可填写假设/反例/下一步并选择状态，保存后提示成功。
- [ ] 修改手牌后重开 Discover，信号按最新数据刷新；已建档信号重算后仍与 Dossier 关联。
- [ ] 重启应用后 Dossier 内容保持不丢。

## 手牌回放（V7.10.0）

- [ ] 任意一手 GG 导入手牌：Hand 列表展开后点「⏵ 回放」，显示分步条牌桌（座位位置、Hero 底牌、公共牌随街累积且新牌高亮、逐街动作 chips、已知投入近似）与下半部全街文字回顾；「结果」步显示摊牌与盈亏。
- [ ] 手工记录的手牌打开回放显示降级视图（提示原因 + 结构化摘要），不报错。
- [ ] 回放是只读的：打开回放、切换街道前后导出数据对比一致。
- [ ] 四套主题下回放样式正常（座位、徽章、chips 均随主题变化），桌面无横向溢出。
- [ ] `file://` 打开离线版后回放行为与 HTTPS 一致。

## 策略与证据（Phase 3）

- [ ] Review 出现「策略」子页，可新建证据包（来源/条件/方法样本/取证时间/转移边界/要点）。
- [ ] 可新建策略修订（family、状态三态、适用范围、策略陈述、复测条件、勾选关联证据）。
- [ ] Radar 已建档信号的编辑器内可「转为策略修订」，草稿预填且不改动手牌数据。
- [ ] 重启应用后证据包与策略修订保持不丢。

## 训练与对手上下文（Phase 4）

- [ ] 策略卡可「生成训练/复测」：BTNvsBB/SBvsBB 生成 Quiz 型单元（可跳转 Quiz 且场景已选中），其他场景生成复测型单元。
- [ ] 策略卡显示基线快照与当前 Radar 的复测判定（频率变化 ≥15pp / 样本增长 ≥50% / 信号消失时提示）。
- [ ] Villain 面板每对手可添加「观察」笔记（带时效），过期笔记灰显，删除可用。
- [ ] 对手行 Live 开关切换后重开应用保持。
- [ ] 重启应用后训练/复测单元与观察笔记保持不丢。

## GTO 基线（V7.10.4）

- [ ] Radar 信号卡显示「🌐 GTO 参考」块：数值、来源条件（40bb 6max）与转移边界清楚标注为结构性参考。
- [ ] 策略子页出现「GTO 基线参考」管理区：4 条种子（BTNvsBB/SBvsBB/COvsBTN）带来源链接与边界，可新增/编辑/停用。
- [ ] 每条 GTO 基线在证据包列表中有对应来源证据（证据纪律留痕）。
- [ ] 重启应用后 GTO 基线与用户新增的基线保持不丢。
