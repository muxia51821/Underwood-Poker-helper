# 用户验收清单

按本次受影响功能选择任务，不逐项执行整份清单。标题中的版本或 Phase 表示首次交付批次；普通操作使用当前入口，只有验证旧版兼容或升级时才准备对应旧数据。日常检查与发布关卡见 [工作流](workflow.md)。

## 从 Session 开始复盘

- [ ] 在整场总览直接浏览本场全部手牌，按时间、盈亏或幅度排序；搜索与筛选不打断输入，超过一页时可翻页。标记一手盈利牌，确认盈亏只显示实际结果，重点标记单独保留；刷新后标记仍在。
- [ ] 从某页深入复盘再回到总览，搜索、筛选和页码仍在。刷新后核对草稿与标记；返回列表时检查页码、展开状态和滚动位置。
- [ ] 深入复盘默认看到疑问与初步判断，计划和学习补充可展开；折叠后保存仍包含原字段。1280px 桌面上保存容易找到，展开更多内容并滚动笔记时保存按钮保持可达。

- [ ] 进入「复盘与学习 → 场次复盘」，先看到按日期倒序的 Session；输入日期、级别或备注，搜索不中断输入。已有未关联手牌仍可通过「跨场查找手牌」访问。
- [ ] 选一场，核对实际关联手牌数、标记／快记关联数和已知个人 BB 盈亏；未知值保持未知，不把场次记录金额当成 BB，也不把盈亏当成决策评分。
- [ ] 查看本场快记与已标记候选，挑一手进入回放；其他场次的快记和手牌不混入。未指定场次的快记由收尾流程核对，不自动归场。
- [ ] 筛选本场手牌、定位行动并写疑问；进入学习后返回，再回到整场总览并重新打开本场队列，核对筛选、所选手牌、行动位置和草稿仍在。「清除筛选」不退出本场。
- [ ] 从「记录与统计」的 Session 行点击「复盘本场」，进入同一总览；本场收尾入口仍能匹配快记、写总结并确认收尾，无关联手牌的场次可导入牌谱。
- [ ] 在 1280×800、1440×900、1920×1080 和手机宽度下完成上述操作；核对四种主题、无横向溢出，并用真实手机确认软键盘不遮挡保存操作。

## 共享交互与反馈

- [ ] 从一手牌带疑问进入主题学习，只看到一处返回原决策和自由学习入口；展开来源可查看原条件、判断与计划，返回仍保留原行动位置和草稿。进入盲练时旧判断和计划仍隐藏。
- [ ] 在四种主题下对比记录页与工作台的主按钮、次按钮和筛选框，外观保持一致；危险确认仍能辨认，禁用、悬停及键盘焦点不混成主按钮状态。

- [ ] Timer 先看到当前阶段、剩余时间和开始／暂停；周期设置默认收起，展开后专注、站立与长休息仍可修改。快速记疑问后返回 Timer；结束牌局仍暂停并进入收尾。
- [ ] 今日日志清除默认聚焦取消，Escape 不删除；确认只清除当日日志，不重置站立次数。提示消息不挡住底层操作，关闭按钮仍能点击或聚焦。

- [ ] 用键盘打开设置，方向键、Home／End 可移动，Escape 关闭后回到设置按钮；声音、振动和当前配色的显示与实际设置一致。
- [ ] 分享与 GG 导入弹窗打开后焦点在弹窗内，背景不可操作和滚动；Tab／Shift+Tab 可循环，关闭后回到可用的原入口。移动端能滚动到操作区。
- [ ] 删除记录或 Session 时先读到影响范围，默认聚焦取消；Escape 和取消不删除，明确确认后才删除。
- [ ] 复制失败能读到原因与手动处理方式，随后可重试；通知可主动关闭，停留阅读或聚焦时不会自动消失。
- [ ] 复盘保存与 GG 写入期间有明确状态，重复点击不会重复执行；失败后控件恢复，复盘输入仍保留。故障模拟使用合成数据。
- [ ] 四种主题及系统减少动态效果下，上述状态仍可辨认。`file://` 无剪贴板权限时有手动处理提示，不要求浏览器提供该权限。

## 策略主题与理论修正（V7.11.16）

- [ ] 不导入手牌也能从策略主题阅读讲解、自测与出处；展开来源可核对教材章节和阅读器页码，答案默认折叠。
- [ ] 打到转牌／河牌的手牌只在支持的前置行动线与位置下显示对应决策卡；到达河牌时，转牌解释仍可查看。相邻场景的教材例明确保留原条件，不变成当前 Spot 的频率或动作建议。
- [ ] Odds 将固定 outs 命中概率、跟注价格门槛与简化 EV 分开；多街路线从所选街道及跟注后的剩余底池／筹码计算。自定义多人池系数标为个人模型假设。
- [ ] 检查 KJo 的具体组合、EQR 与底池权益、混合频率与纯错误的解释；修订后的 Quiz 题使用新题目 ID，其他题目的掌握度与错题记录保持原样。

## 转牌至河牌摊牌样例（V7.18.1）

- [ ] 在「求解研究」选择「转牌样例 C · 河牌只摊牌」，能说明转牌可选动作，以及河牌双方过牌摊牌的条件。
- [ ] 沿过牌／跟注后的分支查看河牌 A♠、T♦；确认概率随当前分支变化，练习时会跳过与底牌冲突的牌。
- [ ] 回到转牌面对下注节点练习。作答前不显示频率和动作期望值；提交后能查看各动作差值及近似等价说明。刷新后继续本轮，结束后从历史回到样例 C 的同一节点。
- [ ] 旧河牌 A／B 及已有练习记录仍可打开，完整备份可保留新旧快照。桌面、手机宽度和断网单文件完成同样流程；记录难理解或重复操作的位置。

## 求解研究与有依据的练习（V7.18.0）

- [ ] 在「复盘与学习 → 主题学习 → 求解研究」选择 A／B。能读出双方范围、起点底池、节点剩余筹码及可选动作，并沿行动路径找到对应决策。
- [ ] 沿过牌分支到摊牌，再切换面对下注的 IP 节点。选中 TT／JJ 类别及一个具体花色组合，能区分类别聚合与组合频率。
- [ ] 点击「练习这个节点」，提交前看不到频率或动作期望值；提交后能找到全部动作的频率、期望值、与最高值的差，以及“在本样例核验精度内近似等价”的含义。
- [ ] 刷新后进入专项练习继续本轮。结束后从历史反馈回到相同研究节点与底牌，仍显示该轮冻结版本；下载完整备份，在隔离环境恢复后再核对。
- [ ] 从个人手牌带疑问进入研究，练一题后返回原决策。疑问与位置保留，来源手牌记录不变；记下卡住和重复操作的位置。
- [ ] 桌面、手机宽度及断网 `file://` 可完成同样流程；检查范围和后续验收项见 [本批验证记录](solution-workspace-validation.md)。

## 备份恢复与场次收尾（V7.16.0）

- [ ] 从「应用设置 → 备份与恢复」下载完整备份；练习页下载入口与场次的数据迁移菜单仍可用。不要清除真实浏览器数据做验收，使用独立浏览器环境恢复。
- [ ] 选择备份后先看到内容数量、冲突和问题项；取消不导入记录。默认保留本地；只勾选一项冲突时，其他本地冲突仍保留。错误记录有定位，必须明确选择跳过才能继续。
- [ ] 确认恢复后显示读回结果，点「完成并刷新」；核对场次／手牌关系、快记、收尾、策略、对手记录、练习历史、旧 Quiz、概念掌握度及错题。设置能恢复；计时保持暂停，主动继续才倒数。
- [ ] 重复导入不增加重复记录；旧 JSON 与复制备份内容可预览。未知扑克键和迁移标记仅进入隔离副本，不直接启用；未知主题使用默认外观但保留原值。
- [ ] 在隔离环境模拟恢复失败后，可以刷新、重新选择原备份重试；从设置下载「恢复前副本」和「原始导入副本」。需要还原时先下载当前备份，再预览还原，核对新增记录被移除、原有记录回到恢复前。
- [ ] 在 Timer 点击「结束牌局，去收尾」，计时暂停并进入待收尾列表；导入本场牌谱后选择对应场次，关联快记、写本场总结并查看候选手牌。
- [ ] 从复盘点击「回到本场收尾」，总结与关联进度保留；标为已看后确认收尾，该场退出待收尾列表。刷新后总结和收尾状态仍在，原始牌谱和盈亏没有被改写。
- [ ] 桌面、手机宽度和断网单文件下，备份、恢复与收尾操作均可完成。

## 决策工作台（V7.15.0）

- [ ] 打开「复盘与学习」，三种模式可达；「记录与统计」仍能录入、收尾、管理对手与策略，练习页能打开旧 Quiz 和掌握度。
- [ ] 找一手打到河牌的牌，停在翻牌并选一个动作，写下疑问与初步判断；进入学习后看到翻牌主题、同一疑问、判断及决策前行动，原条件未知的仍显示未知。
- [ ] 从学习进入练习，同一问题自动带入；回答后回看概念，再回原决策，手牌、街道、行动、筛选和草稿保留。分别检查桌面与手机宽度。
- [ ] 在原节点补充新理解并保存；整手反思、逐决策短记和学习来源可回看，牌谱、盈亏、桌型等事实保留。切到另一节点保存疑问，不会回滚刚改好的整手反思。
- [ ] 刷新能找到原节点和草稿；下载备份并恢复到隔离浏览器，能找回决策短记、草稿以及此前训练进度；旧备份缺少新增字段也能继续导入。
- [ ] 两个窗口看同一手的不同街道，旧窗口继续输入时不会写到另一个街道；遇到空间不足能看到提示，保留当前文字，保存复盘时不会偷偷使用旧草稿。
- [ ] 来源牌谱发生变化时提示重新核对，删除来源后历史练习仍能阅读；自由学习可解除来源关联。个人题提交前，共用来源栏也不能露出后街牌与结果。
- [ ] 断网单文件完成上述主流程；真实手机软键盘与是否减少寻找、往返和犹豫，由木下实际体验验收。

## 专项练习与复习（V7.14.0）

- [ ] 从学习主题进入概念自测，从牌面进入范围练习，从分析手牌进入个人练习；来源、题量和实际条件清楚，未知桌型／筹码不补成 9max / 200bb。
- [ ] 保存一个带学习问题的专项，重开仍保留有效筛选。范围可选整体倾向／频率估计、合并下注／细分尺寸，频率合计不是 100% 时阻止提交。
- [ ] 个人题先在回放核对你的决策时点，再选择街道、动作前缀、决策类型并确认；改变任一条件后重新确认。提交前看不到后街牌、盈亏或原反思；提交后按街查看真实后续行动。
- [ ] 作答后手动进入下一题，结束可见总结、理由、范围假设及待复习项；概念错题自动加入复习。
- [ ] 中途填写后刷新，点「继续上次」可找回草稿；历史可重做标记题或本轮原题，原题条件与评价版本保留。
- [ ] 下载文件，在隔离浏览器恢复；专项、历史、草稿、旧 Quiz、掌握度与错题都保留。已有题 A 加入备份独有题 B，同标识仍保留本地。恢复完成会刷新页面，之后旧训练器继续操作不会覆盖恢复记录。
- [ ] 390px 和桌面完成同样流程；断网打开单文件仍可练习、备份和恢复。真实手机软键盘与实际学习体验由木下验收。

## 每场收尾（Phase 1）

- [ ] 在 Review 的 Session 面板点击「快速记录」，可写一句备注并保存为 Mark，不创建手牌记录。
- [ ] 有手牌的未收尾 Session 行显示「未收尾」徽章，面板顶部显示待收尾计数。
- [ ] 点 🏁 展开收尾工作区：Mark 与 ±5 分钟内的导入手牌可以一键确认关联，也可标"无对应"。
- [ ] 候选手牌清单带来源徽章（Mark/大亏损/高杠杆/星标），可以标"已看"并跳转手牌详情。
- [ ] 「确认收尾」后该场徽章消失、待收尾计数减少；重开应用进度仍在。
- [ ] 从 Timer 结束牌局时先暂停计时，再进入收尾；浏览或编辑收尾记录不会自行启动或重置计时。
