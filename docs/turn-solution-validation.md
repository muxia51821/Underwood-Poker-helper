# 转牌样例实施与验收记录

2026-10-16，7.18.1 本地未发布批次。在两个已核验河牌样例之后，仅扩展一个转牌至河牌摊牌模型，没有扩展为自由下注的完整两街策略库。

## 本批实现

- [数值关卡](turn-solution-verification.md)先于页面接入：转牌、花色置换和两个旧河牌回归均通过。实际原生树包含所有合法河牌与强制过牌，网页只在有选择的转牌节点出题。
- 新增内置样例 C，条件与后续树明确。继续分支可选河牌，查看范围与分支加权概率、公共牌阻断后的具体组合及平均摊牌 EV。
- 题面读取实际街道与河牌限制；恢复时验证这些条件和冻结包一致。历史继续读取原快照，旧河牌包与原报告保持原字节，没有迁移用户数据。
- 修复历史标题误用默认翻牌主题：先建立浏览器复现，确认旧列表显示“翻牌进攻与加注构造”，再改为冻结样例名称、决策节点和本轮疑问。本轮回顾及作答页面也显示样例身份。

## 核查边界

独立检查覆盖双方底牌阻断、每对底牌 44 张河牌、48 张公开候选河牌的分支概率、完整树、全部节点各自策略继续 EV、转牌解析解、双引擎与花色置换。跨引擎 EV 直接对比限于转牌决策，避免把非唯一花色策略产生的不同河牌后验当成求解错误。

产品契约覆盖实际报告与文件哈希、各河牌概率及摊牌 EV 的独立重算、旧河牌包哈希、转牌题面、快照、备份及旧记录兼容。浏览器覆盖桌面、390px、断网 `file://` 的发牌分支、作答、刷新、历史找回与节点返回；完整备份在独立浏览器恢复新旧样例会话。
