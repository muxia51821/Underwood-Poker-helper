# 翻前范围工作区与本轮审查

## 交付范围

本批接续[产品建设顺序](poker-product-direction.md)，完成 Study 内的类别级翻前范围工作区，不新增主导航。原决策的疑问、条件和返回入口继续由已有工作台保留；新范围的默认值是个人目标 Cash / 9max / 200bb，不会冒充来源手牌的实际条件。6max / 100bb 可作为独立范围填写和保存。

- 查看 169 类手牌；选择单格填写范围权重及弃牌、跟注、加注、全下的混合频率。非零权重的动作合计 100%，零权重的动作均为零；未录入保持未知。
- 按对子 6、同花 4、非同花 12 个组合计算已录入部分的加权组合及其占 1326 的比例。没有公共牌及具体花色数据，不做翻后阻断或具体组合比较。
- 条件包含游戏、桌型、有效筹码、双方位置、行动与尺寸、抽水、Ante / Straddle；来源包含名称、网址、方法、授权说明。缺项明确提示，不补造答案。
- 个人范围可编辑、保存版本号；导入的外部参考显示“未核验”，原记录只读，修改需另存个人版本。版本号表示当前范围的修订，不是可浏览的历史版本库；需保留旧版本时主动导出文件或另存一份。
- 可选择已保存范围对照当前手牌；条件不全或不同，立即提示不能据此判断优劣。不计算 GTO 分数、动作 EV 或 EV 损失。
- 元数据、单格未应用输入、批量文本及所选动作保留在本机，切换与刷新后可恢复。显式“应用到矩阵”才改变矩阵；存在未应用单格输入时阻止保存正式版本。批量原文仅作输入草稿，刷新不自动导入。
- 单范围 JSON 导出携带条件、来源、版本及未知扩展字段；完整备份额外包含范围库、草稿和未应用输入。保存失败时可下载页面内的范围与输入草稿备份，再通过“设置 → 备份与恢复”预览恢复。

没有新增运行时依赖或联网请求；没有迁移个人数据、执行 Git 历史操作或发布。首次从未访问且无缓存时仍不能凭空离线加载网页；本批只验证已有应用加载后与独立 `file://` 产物的本地能力，受控缓存更新仍在后续批次。

## 导入边界与开源复用

文本支持 `QQ+`、`AK`、`AKs`、`99-66`、`A5s-A2s`、`KQs-JTs` 及 `:0.5` 形式的 0–1 权重，以逗号、分号或空白分隔。区间两端需采用相同花色类别，且为对子、同首牌或两牌点同向等距变化。每次文本录入只指定一种动作，导入后这些手牌该动作占 100%；混合频率在单格中编辑。确认前显示预览，确认后替换同名格子及其未应用输入。精确花色组合如 `AhKh`、重复手牌、交叉区间、未知写法或无效权重明确拒绝。

JSON 仅支持本应用声明的 `poker-preflop-range` v1 文件。导入前预览覆盖、条件、来源和参考属性；确认后使用新本地 ID，保留原 ID 与版本作为来源，不覆盖已有范围。未承诺 Pio、GTO+、极策或 GTO Wizard 私有格式兼容；不会从界面展示推导数据使用权。

实际复用 [thlorenz/prange 固定版本](https://github.com/thlorenz/prange/tree/6cbf10c3594970a1e1a0de9400ae1ef9dadfdb4c) 的纯解析部分，MIT 许可；在 `src/vendor/prange.js` 内联所需常量、转为 ES 模块、移除未用反向转换，完整版权及许可在离线界面“开源声明”中提供。包装层增加严格语法、权重、重复及区间校验。没有整体引入另一套 UI 框架，也没有将其附带数据当作本项目答案。

## 木下验收

1. 打开“复盘与学习 → 学习 → 翻前范围”，新建范围；填写自己的局面与来源。
2. 点 `AA`，权重填 50，跟注 30、加注 70、其余 0，应用后保存；检查加权组合为 3，其他格保持未知。
3. 在另一手牌留下未完成输入，在批量区填写文本并选动作；切换学习视图、刷新后找回，确认没有自动导入。
4. 导出范围、另存不同条件范围并对照；条件变化应立即出现提示。导入文件先看来源与条件，再确认新增；外部参考先另存后编辑。
5. 点击“备份范围与草稿”，在隔离测试环境的“设置 → 备份与恢复”中预览恢复；不要清空正在使用的个人浏览器数据作试验。

下一批仍是验证一份条件、授权及频率语义完整的答案数据，再接通相同数据源的浏览与练习。本批个人设定不因已能编辑就成为求解结果。
