# Trainer product decisions: implementation audit

本清单逐项核对[Trainer 产品取舍](gto-wizard-observation.md#细读-trainer-指南后的产品取舍)，区分产品改进、实现与明确暂缓项。主线仍为个人 Cash 9max / 200bb，次线 6max / 100bb；题目使用自己的实际条件，未知条件不补成目标档案。

| 原条目 | V7.13.0 核查结果 | V7.14.0 已实现 | 明确保留的边界 |
| --- | --- | --- | --- |
| 场景与牌面 | Study 有筛选，尚无可保存的练习专项 | 保存学习问题、题型与有效筛选；从 Study / Analyze 带入来源；开始前展示实际题量与条件 | 只提供题库支持的筛选。 |
| 选题与相似题 | Analyze 能筛选标记手牌；未成为练习入口 | 标记手牌可进入人工确认的个人练习；概念／范围专项在同主题或类别内选题、复习 | 不把标记叫 EV 接近决策。 |
| 练习跨度 | 有历史回放，没有单决策练习流程 | 单题回答；个人题由用户确认 Hero 决策前缀后冻结题目，提交后才揭示后续 | 不模拟偏离原行动后的分支，不做整手对战。 |
| 动作与尺寸难度 | Study 可合并频率，没有对应练习设置 | 范围倾向先练下注／过牌，可切到尺寸分布；反馈保留原始参考 | 范围频率不判某手底牌的最优动作或尺寸。 |
| 回答方式 | 概念自测已有；范围与个人回答缺失 | 概念选择、范围倾向／频率估计、个人行动＋理由；各自统计 | 不混成 GTO 正确率。 |
| 信息与反馈 | 有阅读资料和旧 Quiz 即时反馈，缺独立会话 | 提交前只展示题目事实；提交后对比回答与参考／真实后续，保留解释和用户范围假设 | 不编造精确对手范围。 |
| 节奏与回顾 | 旧 Quiz 有下一题；缺统一历史与恢复 | 手动下一题、本轮总结、复习项、历史、刷新继续、文件备份与恢复 | 不新增倒计时、自动跳题、多桌。 |
| 评价语义与 RNG | 旧范围 Quiz 有遗留阈值，新工作区未改判 | 新会话冻结题目条件、来源与评价版本；历史按题型分别展示；旧记录保持原义 | RNG、组合评分与 EV 损失继续不启用。 |

上表前七项包含交互与学习流程的产品改进；第八项同时规定数据可信度。全部条目均需验收，但“暂不做”的能力不应被实现成没有答案数据的占位模式。
