# Poker redesign blueprint

## 定位与设计边界

本方案面向木下的个人 Cash 使用：主线 9max / 200bb，次线 6max / 100bb。新版仍是综合牌桌助手，串起牌局准备、时间管理、快记、手牌复盘、策略研究、训练与后续复测。

设计首先解决木下的实际使用问题：牌局中能快速留下疑问，赛后能找到并理解值得复盘的手牌，学完能进入对应练习，下一次能看出自己在哪些决策上有进展。GTO Wizard 提供方法与交互参照；页面数量、设置项、评分样式和操作步骤按这些任务独立取舍。第三方套餐、额度、存储方式与接口不进入产品验收。

设计依据分开保存：[GTO Wizard 调查](gto-wizard-observation.md)记录观察与来源；本文确定推荐的产品行为；[实施路线图](poker-redesign-roadmap.md)负责技术选择、数据兼容、离线机制及实施验收。本文是待实现的设计，不描述当前应用已经具备的行为。

木下已确认新版以网页应用为主，核心能力支持离线缓存，取消必须单文件双击使用的要求。现有 AGENTS.md、CONTEXT.md 和架构文档描述的单文件约束继续适用于旧应用；进入对应实现批次时，按本次已确认方向同步这些文档和产物检查。本阶段不修改旧应用。

用户数据继续只在本地保存，外部链接由用户主动打开。GTO Wizard 用作研究与学习参照，不成为新版运行时服务。没有对应策略数据时，不展示组合级答案或 EV 损失。

## 推荐方案与首版重点

新版围绕“把一场牌局里的疑问变成下次能用的判断”组织产品。首页接续未完成任务；牌局页保持安静；复盘把事实与判断放在一起；学习与练习接在具体问题之后。

首版优先完成四个可感知的改善：

1. **快记之后找得回。** 牌局中不用填完整手牌，赛后通过场次和时间匹配；匹配不确定时由自己确认。
2. **复盘有清楚的先后。** 先看决策时已知的事实，再看后续和参考；事实、推测、复盘结论有各自位置。
3. **学完就能练到对应问题。** 从主题、策略或自己的手牌进入练习时保留上下文；没有对应题目就回到材料，明确缺口。
4. **练过之后能接着用。** 保存本轮回答、理由和需要复习的题，把一条关注点带到下次牌局准备；进展同时看学习记录和新实战样本。

首版不安排多桌训练、限时自动行动、solver 对战和组合级自动评分。这些能力不是首版完整使用链的前提。保留现有计时、赔率、统计、对手和资料价值，重做它们的入口与连接方式。逐项依据见[能力依据与用户收益](#能力依据与用户收益)。

## 信息架构

### 桌面导航

左侧保留稳定导航，右侧提供当前任务的主工作区。顶部仅放观察档案、存储状态、当前任务和设置；观察档案不能被误认为所有参考资料的适用条件。

| 页面 | 子视图与核心内容 | 默认下一步 |
| --- | --- | --- |
| 首页 Home | 当前计时、未收尾场次、待复盘手牌、最近练习、待复测策略；周期回看作为二级页 | 继续未完成任务；无任务时开始牌局或导入手牌 |
| 牌局 Play | 计时、休息、牌局准备、结束与收尾入口 | 开始 / 结束计时，留下 Mark |
| 复盘 Review | 手牌、场次、发现与 Radar 研究记录 | 查看具体样本，留下判断与下一步 |
| 学习 Study | 主题目录、概念、个人策略、证据资料 | 阅读某个主题、核对条件、开始相关练习 |
| 练习 Practice | 专项列表、范围倾向题、概念题、个人手牌盲测、练习历史与错题 | 继续上次专项，或从已确认策略创建专项 |
| 工具 Tools | 赔率、SPR、MDF、隐含赔率、几何下注路线与有范围声明的速查 | 输入条件并查看计算解释 |
| 对手 Opponents | 别名、观察笔记、桌况与 Live 状态 | 从相关手牌补充一条有时间与范围的观察 |

数据备份、导入恢复、主题、提醒和应用更新统一放入设置。与单手牌有关的对手入口也出现在手牌详情中，不要求先返回导航。

### 手机导航

底部固定五项：首页、牌局、复盘、练习、更多。更多包含学习、工具、对手、周期回看和设置。页面名称与桌面一致，不能建立两套独立业务流程。

首页、牌局和复盘提供快记入口。计时运行时，在其他页面保留紧凑的计时状态和返回按钮；快记关闭后回到原页面和原滚动位置。手机详情使用完整页面，返回后保留列表筛选与位置；桌面可采用列表与详情并排。

### 工作区规则

- 常规页只保留一个主要操作，次要动作靠近其对象；导入、开始计时、开始练习不同时争夺主按钮。
- 筛选区展示实际生效的条件，并能一键清除。未知桌型、未知有效筹码保留为未知，不能补成目标档案。
- 空列表区分没有数据、筛选无结果和当前条件没有可用参考；各自提供相应操作。
- 用户输入草稿在切页时保留；删除、导入和恢复要明确影响的对象，操作完成后提供可理解的结果。
- 保留当前主题选择，使用现有颜色变量统一新布局；不从 GTO Wizard 复制品牌、图标或付费素材。

## 主要页面规格

以下为结构草图，数字、手牌与文字均为设计示意，不代表读取了个人数据或已实现界面。桌面以 1440px、手机以 390px 推演；实际断点由内容决定，手机不能缩小照搬桌面双栏。

### 首页：打开后知道下一步

首页按当前任务决定主操作：正在计时 → 返回牌局；已结束但有待收尾场次 → 继续收尾；其余情况提供“开始牌局”。导入手牌始终可在复盘入口找到，无数据时也提供快捷入口。训练中断显示为可继续的次要任务，不抢占正在进行的牌局。

```text
┌──────────┬──────────────────────────────────────────┐
│ 导航     │ 目标档案 9max / 200bb     本地保存 · 设置 │
│          ├──────────────────────────────────────────┤
│ 首页     │ 接着完成这一场                           │
│ 牌局     │ 牌局已结束 · 还有 2 条快记待关联          │
│ 复盘     │ [继续收尾]                               │
│ 学习     ├──────────────────────┬───────────────────┤
│ 练习     │ 值得再看             │ 最近在学          │
│ 工具     │ 具体手牌 / 疑问      │ 主题 / 专项       │
│ 对手     │ [打开这手牌]         │ [继续练习]        │
│          ├──────────────────────┴───────────────────┤
│          │ 周期回看：近期关注点与尚缺的实战样本     │
└──────────┴──────────────────────────────────────────┘
```

首屏不铺满总盈亏、图表与徽章。周期数据在回看页比较，首页只给能继续的对象；没有对象时给真实空态和一个入口。目标档案与手牌实际档案始终分开标注。

### 牌局：计时与快记保持轻量

开始前只展示档案、休息节奏和可跳过的本次关注点。开始后计时占中心，暂停、休息、结束靠近计时；不在旁边常驻赔率、训练答案或实时策略提示。结束进入收尾，也可先离开，首页保留入口。

手机快记使用不离开当前任务的底部面板：时间自动填写，可直接保存，备注与位置为选填。已有疑问标签可点选，但不要求填牌面、底池和行动线。保存成功后面板关闭，页面显示一条可撤销提示；写入失败时保留内容并给重试，不假装保存。

### 场次收尾：一次处理完一场

页面顶部固定当前场次、来源、实际桌型、时间范围和进度。正文按“导入核对 → 快记匹配 → 值得复盘 → 完成收尾”展开，每一步都可跳过并留下未完成原因；没有快记的场次直接进入候选手牌。

| 区域 | 优先显示 | 主要操作与完成条件 |
| --- | --- | --- |
| 导入核对 | 新增 / 重复 / 冲突 / 无法识别的数量及样例 | 确认导入；冲突不静默覆盖。 |
| 快记匹配 | 快记时间、备注、候选手牌；显示匹配理由 | 确认关联或保留待匹配；不确定时可跳过。 |
| 值得复盘 | 主动标记、大底池和当前关注点的候选；注明推荐原因 | 选一手打开详情；候选不自动变成“错误”。 |
| 收尾 | 本场一句话、待复盘清单、后续关注点 | 保存收尾；保留未解决项，允许重新打开。 |

用户打开手牌后返回，仍在同一场次和同一步骤。导入成功与收尾完成分开显示，不要求为了“完成”把所有候选手牌都写一遍。

### 手牌复盘：事实、判断与后续行动

```text
┌─────────────────────────────────────────────────────┐
│ 返回本场次 · 保留筛选     时间 / 桌型 / 位置 / 来源  │
├─────────────────────────────┬───────────────────────┤
│ 手牌与公共牌                │ 我的判断              │
│ 翻前 → 翻牌 → 转牌 → 河牌    │ 当时考虑什么          │
│ 当前街之前的行动            │ 哪个条件最影响决定    │
│ [上一步] [下一步] [原文]    │ 可补充参考与反例      │
├─────────────────────────────┤                       │
│ 当前决策相关参考            │ [保存复盘]            │
│ 条件 / 来源 / 可比范围      │ [用这手牌盲测]        │
└─────────────────────────────┴───────────────────────┘
```

收益与事后标记放在明确的结果区；逐街阅读可主动展开，盲测模式则提交前不显示。手机依次显示当前决策、行动、个人判断、相关参考；主操作随当前任务变化，打开表单时优先保存，保存后提供进入练习。原文、对手和研究记录按需展开，返回后保留所选街道与草稿。

### 学习：一篇材料接一个可回答的问题

主题页先列本主题解决什么问题、适用条件和短解释，再给自己的相关手牌、个人策略及参考资料。正文后只有一个对应的“练这个问题”入口；多种题型可用时说明各自练什么，再让用户选择。无需创建个人策略也能直接做概念自测。

个人策略编辑保留来源、适用条件、反例与修订，深层研究表单按需打开；不能为了开始一道题先完成整套研究表格。阅读材料和练习反馈复用同一份概念内容，避免两套解释逐渐矛盾。

### 练习：准备、作答、对比与带走一条规律

准备页分为“继续上次”“我的专项”和“快速开始”。首次没有记录时只展示可用题型，每项用一句话说明回答对象。选定后首屏保留题量、题型、实际适用条件和反馈方式；高级筛选折叠，学习问题可选填。

```text
准备：范围倾向 · BTN 对 BB · 翻牌
条件：旧参考，桌型与筹码未记录
本轮：10 题 · 逐题反馈                  [开始练习]

作答：第 3 / 10 题                     [结束本轮]
当前牌面与已知条件
“先估计这个牌面下整体下注与过牌的分布。”
[我的估计]                             [提交]

反馈：我的回答 / 参考分布 / 条件说明
可用的概念解释 · 相似题 · 一句可选笔记  [下一题]

总结：已完成 / 待复习 / 本轮关注点
[复习这些题] [回到相关材料] [保存一条规律]
```

练习中隐藏无关导航内容，但保留退出入口和简洁计时状态。下一题固定在反馈后，避免作答按钮位置突然变化造成误触。测试模式结束前不显示答案和暗示；盲测的总结用“已完成复盘 / 待看”，不用“答错”。范围题回顾用“估计与参考的差别”，不借用组合级的 GTO 正误。

手机一屏优先容纳条件、题目和回答区域，解析在提交后顺序展开；不同时展示桌面式侧栏、矩阵与长解释。最后一题按钮明确写“查看本轮总结”，未完成退出写“结束并保留记录”。

### 工具、对手与周期回看

工具按计算任务组织，输入旁标明单位、公式假设与结果含义；更换页面不清空当前输入。对手页先搜索别名或从手牌进入，详情显示观察时间、来源手牌与适用范围，新增笔记不改写历史手牌事实。

周期回看并列展示牌局记录、重复疑问、学习与训练、个人策略四部分；每个结论都能返回样本或回答。最后选择一个下次关注点即可结束，不要求填写长周报。

## 核心使用流程

### A. 牌局准备与进行

首页 → 牌局 → 确认目标档案、休息提醒和本次关注策略 → 开始计时。

准备页显示最近一次由用户选中的关注策略，可以跳过。策略只作赛前提醒，不根据实时局面推荐 fold / call / raise。计时模块只负责时间事实，准备与收尾在上层编排。

进行中可创建只有时间与短备注的 Mark；Mark 不要求先有完整手牌。结束后保存时间日志，进入收尾入口；不凭计时直接生成未经核实的 GG 手牌 Session。需要关联导入场次时，让用户确认对应关系。

### B. 导入与场次收尾

复盘 → 导入整理后的 `.txt` → 预览识别数、重复数、冲突与异常 → 确认导入 → 选择场次 → 匹配 Mark → 查看候选手牌 → 保存收尾。

候选的来源、已有标记和关联状态可见。时间相邻只是匹配建议，用户可以跳过或修正；不把 Mark 内容覆盖到原始手牌。已关闭场次可回看与重新打开，重新打开保留原记录。

导入后的重复与冲突规则沿用已验证的协调层，再由合成回归覆盖。换级别和跨桌型不得因新页面布局而合并成同一策略样本。

### C. 单手牌复盘与研究

手牌列表 → 回放与原文 → 逐街查看 → 写决策理由、错误和反思 → 关联研究或策略 → 创建后续练习。

桌面详情优先展示牌面、Hero 位置、已知筹码与行动线；备注、来源、对手观察在相邻区域按需展开。手机使用同样顺序，避免把长解释塞在行动按钮上方。

实际行动与复盘观点分开呈现。参考资料显示自己的条件、来源及适用边界；不能把文章中的 6max / 100bb 解默认为个人 9max / 200bb 答案。解析不完整的手牌保留摘要与原文入口，不生成缺失行动。

Radar 发出的是待核查候选。进入后先看到样本、分母、范围和反例入口，再决定建立研究记录、维护策略或继续取证；不自动将个人频率与异条件 GTO 参考做差值。

### D. 学习、专项与复练

主题或个人策略 → 提出一个具体学习问题 → 查看解释和条件 → 创建专项 → 确认题型与题量 → 作答 → 对比复盘 → 本轮总结 → 重做需要复习的题。

专项可保存 `learningQuestion`，用一句话说明想理解什么；从手牌或策略创建时预填，也可快捷选择或修改，不要求用户为开始练习再填一张表。自由练习可以直接开始。例如“BTN 对 BB 的单次加注底池，在单色翻牌上如何分配下注与过牌”，这一问题与所选条件一起显示在开始页和总结页。训练对象是学会某个条件下的决策规律，不把增加答题量本身作为完成标准。教学依据见[调查中的官方训练方法](gto-wizard-observation.md#官方训练方法与本轮观察重点)。

专项保存可用条件和来源引用，不把一次导航状态当成持久化专项。没有可用题目时说明缺少的是题库、匹配条件还是答案，不把用户送到无关题库。修改专项只影响以后的练习，历史保留当时配置和来源修订。

题型、练习跨度和难度分别定义：范围 / 概念 / 盲测说明回答对象；单节点 / 单街 / 整手说明跨度；简化动作 / 分组尺寸 / 精确尺寸说明答案粒度。首期只启用题库确实覆盖的组合，不用几个模式按钮冒充完整的整手对战引擎。某些维度不适用时不显示设置。

开始页展示实际生效条件，明确区分固定筹码与混合筹码。混合专项逐题显示来源条件，统计按条件分组；不得把不同深度拼成一个看似同条件的正确率。每题动作集合取自该题数据；现有范围题继续使用其已有动作列，未来组合级数据不预设只能下注 33% / 50% / 75%。

默认每轮 10 题，也可选择 5 或 20 题；题库不足时按实际可用题数开始，不用重复题伪装覆盖率。支持训练与测验两种反馈时机：训练逐题解释；测验提交后只记录回答，到结束时统一显示答案。首次默认训练模式，首期不限时、手动下一题；以后若加入自动跳题或限时，必须由用户显式开启并独立验收。

本轮状态包括作答、提交、反馈、下一题和结束。提交只记一次；结束后返回总结。刷新恢复时保留已提交答案，未提交答案作为草稿恢复，不能因页面重载新增一次尝试。中途结束标为未完成，未答题不计错。

练习历史按专项和题型查看题量、回答与复习项。概念题可统计正确率；范围倾向题显示与参考的比较；盲测显示是否完成理由及复盘。不同题型不合成一个“GTO 分数”。

作答后的对比复盘先展示回答与参考的差别，再提供与该题条件相符的机制解释、对手范围及相似场景入口。个人手牌中没有对手范围事实时，让用户记录范围假设及理由，不由系统编造精确范围。首期相似场景按已有题目类别、主题或候选手牌链接提供；没有材料就说明缺口。

总结页保留“本轮学到的规律、适用条件、一个反例或待核查点”的可选短记，并能回到产生该判断的题目。范围学习和实战调整仍需来源与样本，不能因一道题答对就自动形成个人策略。

### E. 周期回看与策略复测

首页 → 周期回看 → 检查场次与样本范围 → 查看待收尾、重复问题、策略和练习 → 写本周重点 → 进入下一次牌局准备。

真实牌局的变化与训练结果并列呈现，不把练习答对推成实战盈利改善。策略复测沿用可追溯的基线快照与新样本；新增提醒说明触发条件，由用户决定维护、调整或继续研究。

### 一次完整使用示例

以下是用于后续验收的合成情境：用户在一场 9max / 200bb 目标牌局中，对翻牌下注后的防守产生疑问。目标档案不是该手实际有效筹码的证明，题目与参考仍使用各自已知条件。

1. 牌局中创建快记“这里跟注依据是什么”，继续计时，不必录入完整行动。
2. 赛后导入合成手牌，收尾页给出时间附近的候选；用户确认关联，保留快记原文。
3. 在手牌详情先看面对下注前的行动、已知底池与尺寸，写自己的范围假设，再展开真实后续。记录“有疑问”，不由系统认定这是错牌。
4. 打开防守主题复习适用条件；做相关概念自测。现有范围题只有进攻方翻牌聚合频率，因此不把它冒充为这手防守决策的标准答案。
5. 选择个人手牌盲测，重新陈述行动与理由；提交后对比自己原先的判断、真实行动和复盘笔记。没有匹配解答时保留待核查项。
6. 把“先核对尺寸和范围，再判断防守”保存为下次关注点。下一周期查看新的相似手牌与理由，不把题库成绩当作实战改进的证据。

这条路径即使没有组合级策略库也能完整成立。后续可先验收这条主线，再扩展更多题型与复杂度；不要求把所有资料都做成自动评分题。

## 四类练习与判分边界

| 题型 | 用户回答什么 | 答案依据与反馈 | 首轮实施选择 |
| --- | --- | --- | --- |
| 范围倾向 | 某牌面下整体策略更偏向什么；可估计下注 / 过牌分布 | 现有按牌面聚合的参考频率，保留 legacy 条件声明；展示频率差异，不能判具体底牌错误 | 实现，重写旧 Quiz 的问题与评价语义 |
| 概念自测 | 机制、适用条件、反例与边界 | 题库明确答案、解释与出处；记录正确率和错题 | 实现，复用概念内容与稳定题目 ID |
| 个人手牌盲测 | 在已发生的 Hero 决策前选择行动并解释理由 | 提交后展示真实后续、既有复盘及匹配参考；真实行动不是标准答案 | 实现，只记练习与人工复盘，不自动判 GTO 对错 |
| 组合级 GTO | 给定底牌、范围和完整节点的动作或混合频率 | 条件匹配的组合级策略；仅有动作频率时不能计算 EV 损失 | 暂不实现，先具备可使用且来源明确的数据，再独立验收 |

旧 Quiz 的 35% / 13% 判分标签不作为新版组合级依据。历史回答保持原始记录及评价版本；新版语义不重写旧成绩，不将旧“掌握”直接转换成组合级能力。

个人手牌盲测需要决策级视图：只展示该时刻已知的牌、位置、底池与行动。后续牌面、未来行动、对手摊牌、最终盈亏、结果性标签和事后笔记在提交前全部隐藏。只有逐街摘要且无法切分决策时，不进入自动盲测题池，保留人工选题路径。

首期只开放能够确认行动归属与决策前缀的节点。当前回放可显示匿名行动序列，Radar 的 Hero 归属还包含启发式推断；两者都不能单独作为“可自动盲测”的资格。需要人工选题时，由用户明确指定或补充当时已知的局面，标注为手工练习；若该步仍无法形成明确题目，就提供普通回放与概念学习入口。底池与有效筹码无法从当时信息可靠获得时显示未知，不拿最终底池、Hero 结束筹码或目标档案填充。

组合级数据的最低资格是：牌型与赛制、桌型、有效筹码、抽水与下注树条件、起始范围、完整行动前缀、公共牌、Hero 底牌、动作频率、来源与修订可追溯。EV 缺失时明确不可用，不能填 0 或由频率换算。

## 跨页上下文与数据职责

导航携带来源页面、目标对象和有效筛选，返回后恢复上下文。已有手牌、场次、研究、策略、证据和对手 ID 继续用于关联。URL 只放路由与不敏感 ID，不放手牌原文、备注或外部认证参数。

新增的最小持久化对象为 `DrillPreset`、`PracticeSession`、`PracticeAttempt`；训练 Session 与真实牌局 Session 分开保存。它们需要关联题型、题目 / 手牌 ID、专项、来源修订、适用条件、回答及时间，不复制一套手牌事实。来源发生变化时保留旧修订引用；旧题不可再生成时，历史仍可阅读，复练给出原因。

每次开始固定最小题目快照和对应的参考说明、答案版本，供历史重现当时的条件；快照只用于本次练习回顾，不成为另一套可编辑的手牌库。对个人盲测，作答页只消费决策前投影，提交后才读取匹配的揭示内容。只有 ID 而没有旧修订或快照的历史不能保证重建原题，须标注缺失，不能拿更新后的答案重新评判旧回答。

`DrillPreset` 同时保存学习问题和适用的练习跨度；`PracticeSession` 固定本轮生效配置和可选复盘短记；`PracticeAttempt` 保存该题实际条件与评分语义。若以后支持 RNG，需显式区分关闭、High / Low 等模式及映射规则；只有匹配的混合策略数据才允许按随机目标评估，不在现有聚合题上伪造逐手随机化答案。官方规则与本轮未验证的 RNG 行为分别记录在调查中。

领域行为与 DOM 编排分开：计时、解析、导入、存储、观察、研究、策略、训练分别拥有自己的状态；页面调用这些能力，不在新首页重写它们。具体模块复用判断见[路线图的能力清单](poker-redesign-roadmap.md)。

## 产品验收

- 桌面 1280 / 1440 / 1920 宽和手机 390 / 430 宽完成同一条端到端使用链；可用键盘操作，主要触控目标至少 44px，无页面级横向滚动。
- 使用合成手牌完成开始计时、Mark、导入、确认关联、收尾、复盘、策略、专项、反馈、错题和周期回看，跨页返回不丢上下文。
- 分别验证四类题型的入口与边界；组合级训练在没有资格数据时不显示可开始按钮，范围题与盲测不输出单手 EV 或未经验证的 GTO 对错。
- 盲测提交前的可见 DOM、可访问名称和提示不含未来牌、摊牌或结果；下一街只能在提交后展开。
- 训练地址不含未来公共牌、对手底牌、答案或结果性备注；分享链接只描述可分享的配置，个人手牌 ID 仅在用户本地解析。
- 固定专项与混合条件专项分别验收；复练保留原题条件与来源，不自动新增已提交作答。切换题目时保留已有选择和理由草稿；只有会丢失已输入内容时才提示确认。
- 数据恢复及断网、首次访问、缓存完成、更新和恢复场景，按[路线图](poker-redesign-roadmap.md)验收。
- 以上均为新版实施后的验收要求；本次文档交付不代表界面、迁移或离线能力已经通过验证。

### 体验验收与观察方法

后续每批录制同一组合成任务的桌面与手机操作，记录任务能否完成、往返页面次数、重复输入与发生卡住的位置。旧界面只作为现状比较，不把自动化通过当作体验改善。

| 任务 | 可直接判定的体验标准 |
| --- | --- |
| 牌局中快记 | 打开后无需必填即可保存；回到原任务；失败时文字仍在。 |
| 导入与收尾 | 能辨认新增、重复与异常；关联快记后再打开手牌可返回原场次步骤。 |
| 手牌到学习 | 题型与该问题相关；不因无匹配答案而跳到无关频率题。 |
| 完成一轮练习 | 首次使用即可分清题目与反馈；最后一题有清楚的结束动作；记录能回看和复习。 |
| 练后回到实战 | 可选一条具体关注点，在下一次准备页找回；不用重新抄写上下文。 |

先满足这些行为，再用真实试用记录比较速度；目前没有新版试用基线，不虚构节省百分比、完成秒数或学习收益。
