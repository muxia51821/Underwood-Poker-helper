## 验证

- 原生双引擎及独立枚举：见数值报告与机器结果，不以网页构建替代数学验证。
- 独立辅助检查：牌型枚举、阻断、零兼容判定；运行 `python tools/solver-lab/test_lab.py`。
- 产品契约：SHA-256 与 Node 对照、双包及实际数值报告关联、加权聚合、未知／零、加权抽题、混合动作、快照关联、备份恢复、保存配额失败。
