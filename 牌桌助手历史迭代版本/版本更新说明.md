## V6.7

- **V6.7.1** — 存储底座升级：localStorage → IndexedDB（M1 里程碑）
  - **IndexedDB 主存储**：新增 `DB` 对象封装 IndexedDB（pa_store 数据库，4 个 Object Store + handReviews 含 3 个索引）。handReviews/sessions/weeklyReviews/tiltLogs 四张大表从 localStorage 迁移到 IndexedDB，突破 5MB 上限。
  - **内存缓存层**：`BaseRepo` 增加内存缓存（`_cache`），`getAll()`/`saveAll()` 操作缓存（同步），后台 300ms 防抖异步写入 IndexedDB。对外 API 签名完全不变，35 个调用点零改动。
  - **自动迁移**：首次启动检测 IndexedDB 为空 → 从 localStorage 逐表迁移 → 校验记录数一致 → 标记 `pa_migrated_v1` → 删除 localStorage 大表。迁移失败保留 localStorage 数据，下次启动重试。
  - **隐私模式兼容**：IndexedDB 不可用时（隐私模式/旧浏览器），所有 Repo 自动退化到 localStorage，功能完全不受影响。
  - **数据完整性**：启动时检测各 Repo 缓存是否为数组，损坏时自动从 localStorage 恢复。导入备份时 Schema 校验（sessions/handReviews 等字段类型必须为数组）。
  - **安全网**：`beforeunload` 事件紧急 flush 缓存到 localStorage，防止页面关闭时 IndexedDB 写入未完成导致数据丢失。
